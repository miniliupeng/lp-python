# 专题 02：函数签名设计、专用参数 (/ 与 *) 与 LEGB 作用域体系

函数是 Python 系统的一等公民（First-Class Citizens）。编写高可用基础库与企业级框架时，严密的函数签名设计（**PEP 570 位置专用参数 `/`** 与 **关键字专用参数 `*`**）是确立调用契约、保持向后兼容的关键；而深入理解 **LEGB 作用域解析** 与**闭包延迟绑定机制**，更是避免生产中状态错乱的核心功底。

---

## 一、 痛点驱动：参数传递的不可控演进与闭包延迟绑定

1. **库作者的向后兼容噩梦（形参重命名破裂）**：
   - 开发者定义 `def connect(host, port)`，调用方习惯写关键字调用 `connect(host="127.0.0.1", port=8080)`；
   - 未来底层重构将形参重命名为 `server_ip`，外部调用代码全部直接抛出 `TypeError` 崩溃；
2. **循环构造闭包的经典延迟绑定灾难**：
   - 在循环体中创建 lambda 或局部函数时，内部引用的循环变量并未在定义时求值，导致最终执行时所有闭包都读取到循环的最后一个终态值。

---

## 二、 机制解密：PEP 570 签名边界与 LEGB 寻址拓扑

```text
[ 现代严密函数签名分界线 ]
  def api_call(pos_only, /, standard, *, kw_only):
               ▲        ▲             ▲
               │        │             └─ 之后必须使用关键字传参 (kw_only=...)
               │        └─ 之前必须使用位置传参 (禁止指定形参名)
               └─ 允许重命名形参名而不破坏外部调用契约

[ LEGB 作用域查找拓扑 ]
  Local (函数局部) ──> Enclosing (外层闭包) ──> Global (模块全局) ──> Built-in (内置)
```

1. **`/` 与 `*` 的工程价值**：
   - **`/`（位置专用）**：强制调用方不能使用关键字传递前面的参数，为库维护者提供了自由重命名内部参数名的绝对安全权；
   - **`*`（关键字专用）**：强制后续参数必须显式写出参数名（如 `timeout=5.0`），提升调用处的可读性，防止布尔/数值等无语义参数误传。
2. **闭包延迟绑定本质**：
   - Python 闭包内部记录的是**变量符号的指针引用**，而非创建时的瞬时值快照。只有通过将外部变量作为默认参数（`lambda x=i: x`）或通过 `functools.partial` 显式传递，才能在定义期完成立即求值锁定。

---

## 三、 生产规范与最佳实践

- **布尔配置强制关键字专用**：只要函数包含影响行为的布尔参数（如 `purge_cache=False`），必须放在 `*` 之后，禁止位置传递；
- **跨层闭包修改显式使用 `nonlocal`**：避免在闭包内隐式新建局部同名变量导致外部状态未能更新。
