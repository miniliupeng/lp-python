# 大厂高频面试题精讲 (02-mutability-and-deep-shallow-copy)

---

### Q1: 浅拷贝（Shallow Copy）与深拷贝（Deep Copy）的底层内存机制有何本质区别？

#### 🎯 面试官考点
- 复杂对象图（Object Graph）遍历算法、浅拷贝顶层引用复制与深拷贝递归内存分配。

#### 💡 满分回答模板
1. **浅拷贝（Shallow Copy，如 `copy.copy(obj)`, `list[:]`, `dict.copy()`）**：
   - 仅在堆上分配一个**新的最外层容器对象**；
   - 容器内部包含的所有子元素对象，仅仅是**原样复制了指针地址（引用）**。
   - **后果**：如果子元素是可变对象（如列表、字典），在任一方对子元素进行修改，两边都会同步感知篡改。
2. **深拷贝（Deep Copy，如 `copy.deepcopy(obj)`）**：
   - 沿对象图做**完全深度递归遍历**；
   - 不仅为最外层容器创建新实例，为其中包含的所有可变子对象、子对象的子对象全部在堆上重新分配全新的物理内存，并复制数据；
   - 两者之间彻底切断指针联系，实现 100% 的物理级上下文隔离。

### Q2: 为什么在函数定义中绝对禁止写 def append_item(item, target=[])？底层字节码是如何处理默认参数的？

#### 🎯 面试官考点
- Python 解释器函数对象定义加载期（Compile/Load Time）与调用期（Runtime）的执行时序解耦。

#### 💡 满分回答模板
1. **底层机制解密**：
   - Python 的函数是头等公民对象。当模块加载执行到 `def` 语句时，解释器对该函数进行编译并创建 `PyFunctionObject`；
   - 关键点：**默认参数表达式是在函数定义（加载期）仅被求值一次**，并以元组形式存储在函数的 **`__defaults__`** 内部属性中；
   - 随后在每一次业务请求调用该函数时，解释器不会再次新建列表，而是将形参 `target` 直接绑定到 `__defaults__` 中的那个全局唯一列表上。
2. **生产灾难后果**：
   - 在高并发或循环调用中，所有未显式传参的调用都会向该唯一列表追加数据，导致用户 A 的敏感数据被残留给用户 B，引发严重串扰。
3. **标准生产解法**：
   - 使用不可变单例 **`None`** 作为哨兵参数，并在函数体内部显式判断后就地创建新容器。

### Q3: copy.deepcopy() 是如何解决对象之间的“循环引用（Circular References）”导致无限递归爆栈问题的？

#### 🎯 面试官考点
- 深度优先搜索（DFS）遍历算法、备忘录模式（Memoization）在内存拷贝中的应用。

#### 💡 满分回答模板
1. **备忘录字典字典（Memoization Dictionary）机制**：
   - `copy.deepcopy()` 底层实现中接受一个核心内部参数 **`memo = {}`** 字典；
   - 在递归拷贝任何对象时，首先获取该对象的物理地址 `id(x)`；
   - 算法在进入递归前，**第一时间把当前拷贝出的新对象存入 memo 表**：`memo[id(x)] = y`；
2. **环路剪枝（Loop Short-circuiting）**：
   - 当拷贝到内部属性如果引用回对象自身（例如 `a.self = a`），算法查表发现 `id(a)` 已经在 `memo` 中，直接返回表内已记录的副本引用，不再继续向下递归；
   - 这种设计不仅彻底避免了无限递归引发的 `RecursionError` 爆栈崩溃，还能 100% 精确还原原始数据图中复杂的自环与多重互引关系拓扑。
