# 常见高频面试题：运算符与短路求值

### Q1: Python 中 `is` 与 `==` 的区别是什么？为什么判断 None 必须用 `is None`？

🎯 **面试官考点**：内存引用比对与富比较重载协议的底层区别，以及防御恶意对象劫持的工程考量。

💡 **满分回答模板**：
1. **核心差异**：
   - `==` 是**值等价比较**（Equality），底层调用左操作数的 `__eq__(other)` 魔术方法，比较对象的内部状态或业务数据。
   - `is` 是**引用同一性比较**（Identity），底层直接比对两者的内存地址（C 层面指针比较，等价于 `id(a) == id(b)`），不可被重写，执行速度为纳秒级。
2. **为什么判断 None 必须用 is**：
   - `None` 在 CPython 解释器全局是唯一的单例对象（`Py_None`）。
   - 若使用 `x == None`，会触发用户自定义类中重写的 `__eq__` 方法。若该类恶意实现 `def __eq__(self, other): return True`，则任何实例与 `None` 比较都将返回 `True`，引发灾难性安全隐患与逻辑穿透。
   - `is` 直接比较指针地址，无法被任何魔法方法覆写劫持，且效率极高。

### Q2: `res = a and b` 与 `res = a or b` 返回的是布尔值吗？底层短路求值是如何运作的？

🎯 **面试官考点**：逻辑运算符短路机制的操作数原样返回特性，以及在工业界设置默认值时的常见 Bug。

💡 **满分回答模板**：
1. **核心机制**：在 Python 中，`and` 和 `or` **并不强制返回 bool**，而是返回**最终决定整个表达式真伪的那个操作数本身**。
   - `a or b`：计算 `a`。若 `bool(a)` 为真，则直接短路返回 `a`；否则计算并返回 `b`。
   - `a and b`：计算 `a`。若 `bool(a)` 为假，则直接短路返回 `a`；否则计算并返回 `b`。
2. **工业级避坑**：
   - 常见反模式：使用 `timeout = user_timeout or 30` 设置默认超时。若用户传入合法的 `0`（代表非阻塞），`0` 在布尔上下文中为 `False`，导致其被错误降级为 `30`。
   - 解决方案：使用三元表达式防御性校验哨兵：`timeout = user_timeout if user_timeout is not None else 30`。
