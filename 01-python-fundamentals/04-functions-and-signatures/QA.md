# 常见高频面试题：函数机制与签名设计

### Q1: 为什么 Python 严禁使用可变对象（如列表、字典）作为函数默认参数？底层机制是什么？

🎯 **面试官考点**：考察函数对象创建生命周期、`__defaults__` 内部属性，以及代码防御意识。

💡 **满分回答模板**：
1. **底层机制**：
   - Python 的函数是第一类对象。当模块被解释器加载编译时，`def` 语句执行并构建该函数对象。
   - **默认参数表达式在函数定义（Def-time）时被求值一次**，并作为元组持久保存在函数对象的 `__defaults__` 属性中。
   - 每次调用函数时，若未显式传参，实参形参指针直接指向该静态预存的 `__defaults__` 对象。
2. **陷阱后果**：
   - 若默认参数是可变类型（如 `[]` 或 `{}`），在函数体内的修改（如 `append`）会直接持久化修改 `__defaults__` 里的对象。导致后续所有不带参调用的结果互相污染。
3. **标准生产范式**：
   - 必须使用不可变的 `None` 作为哨兵标记，在函数体运行时通过 `if target is None: target = []` 进行延迟动态初始化。

### Q2: Python 函数签名中的 `/` 和 `*` 分别代表什么含义？在框架设计中有何价值？

🎯 **面试官考点**：PEP 570（位置专用参数）与 PEP 3102（关键字专用参数）的规范与大型框架 API 演进设计。

💡 **满分回答模板**：
1. **符号含义**：
   - **斜杠 `/`（Positional-only parameters）**：位于 `/` **左侧**的所有参数，调用方**只能通过位置传递**，严禁使用关键字形参名（如 `func(10)` 合法，`func(x=10)` 报错）。
   - **星号 `*`（Keyword-only parameters）**：位于 `*` **右侧**的所有参数，调用方**必须通过关键字传递**，严禁通过位置顺序传参。
2. **框架与工程设计价值**：
   - **防止重构破坏调用方（对 `/`）**：当底层函数内部想要重命名某个参数名（例如将 `path` 重命名为 `uri`）时，使用 `/` 能确保外部调用者不会因使用了旧关键字名导致向后兼容性断裂。
   - **杜绝布尔盲区与传错参数（对 `*`）**：避免出现 `configure(True, False, 10, None)` 这种严重损害可读性的神秘调用，强制书写 `configure(retry=True, verbose=False, timeout=10)`。
