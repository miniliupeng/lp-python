# 04-functions-and-signatures: 函数签名与参数解构深度

## 一、核心机制与设计哲学

- **一等公民（First-Class Citizens）**：Python 中函数是真正的对象（`function` 类的实例），可以作为参数传递、作为返回值返回、赋值给变量或存入容器。
- **参数传递本质：传对象引用（Call-by-object-reference）**：
  - 传递参数时，实参将所引用的 PyObject 指针复制一份传给形参局部变量。
  - 若对象为**不可变类型**（int/str/tuple），函数内重新赋值仅改变局部指针绑定，不影响外部；
  - 若对象为**可变类型**（list/dict/set），在函数内调用就地变异方法（如 `append`/`pop`）会直接影响外部对象状态。
- **默认参数求值时机**：函数的默认参数在**函数定义（模块加载字节码阶段）仅求值一次**，而非在每次函数调用时重新创建。

## 二、生产规范与避坑指南

1. **默认可变参数陷阱（Mutable Default Argument Trap）**：严禁使用 `def func(items=[])` 或 `def func(tags={})`。所有调用将共享同一个堆内存列表！必须使用 `None` 作为哨兵：`def func(items: list | None = None)` 并在函数体内动态初始化。
2. **位置专用与关键字专用形参（PEP 570 / PEP 3102）**：
   - `/` 之前的所有参数为**位置专用参数**（禁止通过关键字传递）；
   - `*` 之后的所有参数为**关键字专用参数**（强制通过关键字命名传递）。
   - 生产 API 设计中，对布尔开关或多态选项强制使用关键字专用参数，可极大提升调用点可读性并防御重构错位。
