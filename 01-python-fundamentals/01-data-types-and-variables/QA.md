# 常见高频面试题：数据类型与变量模型

### Q1: Python 是弱类型语言还是强类型语言？为什么？

🎯 **面试官考点**：考察候选人对“类型系统分类学”核心定义的掌握，区分“动态/静态类型”与“强/弱类型”的正交概念。

💡 **满分回答模板**：
1. **结论**：Python 是**动态强类型**语言。
2. **机制拆解**：
   - **动态类型（Dynamic Typing）**：指类型的检查发生在**运行时**，且类型信息与堆内存中的对象绑定，而非与变量名声明绑定。变量名仅是 PyObject 指针。
   - **强类型（Strong Typing）**：指一旦对象确立了类型，Python 绝不会在不兼容的操作中进行隐式类型跨界强制转换。例如执行 `1 + "2"` 会直接抛出 `TypeError: unsupported operand type(s)`，而在 JavaScript（弱类型）中会自动隐式转换输出 `"12"`。
3. **工程价值**：现代 Python（3.10+）结合 PEP 484 类型注解与 Ruff/Mypy 静态检查器，已具备工业级“静态强类型”的开发体验与安全保障。

### Q2: 为什么 `0.1 + 0.2 != 0.3`？在电商交易或金融结算系统中该如何解决？

🎯 **面试官考点**：计算机体系结构中 IEEE 754 浮点数表示缺陷，以及金融高可靠系统中选型防灾能力。

💡 **满分回答模板**：
1. **根本原因**：Python 的 `float` 遵循 IEEE 754 标准双精度 64 位浮点数规范。计算机底层采用二进制存储，十进制分数如 $1/10$（0.1）在二进制中为无限循环小数 $0.00011001100..._2$。在有限尾数截断后，相加结果为 `0.30000000000000004`，故与 `0.3` 比较返回 False。
2. **解决方案**：
   - **核心推荐**：使用 Python 标准库 `decimal.Decimal`，它提供基于十进制基数的固定精度算法。
   - **关键避坑**：实例化必须传入**字符串常量**（例如 `Decimal("0.1")`），严禁传入 float（如 `Decimal(0.1)`，此时二进制截断误差已在参数层固化）。
   - **性能权衡**：纯数学密集运算若只要求微小相对误差，可用 `math.isclose(a, b, rel_tol=1e-9)`；高频交易可转为“分/厘”等整数类型（Fixed-point / Integer Cents）运算以兼顾纳秒级性能与绝对精确。
