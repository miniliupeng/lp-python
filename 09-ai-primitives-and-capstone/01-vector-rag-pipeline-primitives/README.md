# 专题 01：极简纯原生向量 RAG 管道（余弦相似度与上下文检索增强）

在当前 AI 原生架构浪潮中，**RAG（检索增强生成，Retrieval-Augmented Generation）** 是解决大语言模型“知识时效性滞后”与“专业领域胡说幻觉（Hallucination）”的核心方案。很多初学者被 LangChain 等第三方框架庞杂的概念所困扰，甚至误以为 RAG 必须安装数 GB 的重量级向量数据库。本专题剥离一切繁杂外壳，以 **60 行纯 Python 原生代码** 揭示向量检索与 Prompt 增强的核心数学与工程本质。

---

## 一、 痛点驱动：外部框架的黑盒臃肿与大模型幻觉

1. **大模型私有知识缺失与幻觉**：
   - 通用大模型（如 GPT-4 / DeepSeek）无法获知企业的内部私有文档、最新业务流水与实时代码库；
2. **重型框架带来的心智负荷与黑盒风险**：
   - 依赖动辄数十万行代码的第三方编排框架，一旦线上检索出现精度下降或延迟飙高，开发人员根本无法穿透黑盒进行数学层面的调优与根因排障。

---

## 二、 机制解密：RAG 极简数学本质（高维空间投影与夹角余弦）

```text
[ RAG 核心三步流水线 ]
  1. 知识库预处理: 文本分块 (Chunks) ──> 向量模型 ──> 高维稠密向量 (Embedding Vector)
  2. 运行时相似检索: 用户问题 (Query) ──> 计算与各向量的余弦相似度 (Cosine Similarity)
                                     └──> 召回 Top-K 最相关片段
  3. Prompt 上下文增强: 组装 [背景知识] + [用户问题] ──> 发送给大模型进行精准推理
```

1. **余弦相似度（Cosine Similarity）数学公式**：
   $$\text{similarity} = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|} = \frac{\sum_{i=1}^n A_i B_i}{\sqrt{\sum_{i=1}^n A_i^2} \sqrt{\sum_{i=1}^n B_i^2}}$$
   - 它度量的是两个高维向量在多维语义空间中的**方向夹角**，值越接近 1 代表语义越吻合，天然消除了文本长度差异对向量模长的干扰。

---

## 三、 生产规范与最佳实践

- **文本切分粒度是效果天花板**：分块过大检索引入噪声，分块过小丢失完整语义（生产推荐 256~512 Token 并保留 10% 重叠 Overlap）；
- **海量向量必建近似近邻索引（ANN）**：文档量超十万级时，必须从暴力全量点积比对切换为 **HNSW（分层可导航小世界图）** 索引。
