# E01　语言与语法题

> 对照示例：`examples/part_e/e01_language.py`。先自己答，再看下面的文字。示例把其中几条钉成了断言。

这些回答按 2026 年的语言现状来写。默认句子属于 Python 3.12 的语义；只在标明版本时才用 3.13 及以后的行为。

### 1. Python 是动态类型，所以是弱类型吗？

**常见错法：** 动态类型就是可以随便相加，解释器会帮你转换。

**回答：** 动态指名字没有固定类型，类型在对象上，运行时检查。强类型指不做隐式的跨类型转换。`"1" + 1` 抛 `TypeError`，不会变成 `"11"` 或 `2`。需要转换就显式写 `int` 或 `str`。示例断言了这次加法失败。

### 2. 参数是传值还是传引用？

**常见错法：** 二选一。对象是传引用，数字是传值。

**回答：** 调用和赋值是同一套规则：形参名被绑到传入的对象上。没有把对象复制一遍，也没有把调用方的变量名交出去。重新绑定形参，调用方的名字不变。就地修改可变对象，调用方看得到，因为两边指着同一个对象。数字不能就地改，所以看起来像“传了值”。

### 3. `is` 和 `==` 的差别？小整数呢？

**常见错法：** `257 is 257` 一定为假，因为缓存只到 256。

**回答：** `==` 比较值，`is` 比较是不是同一个对象。业务上的数值用 `==`。`None` 用 `is`。CPython 会缓存 `-5` 到 `256`，要用 `int("256")` 这种动态构造来观察。同一代码对象里的字面量还会共享常量，所以函数里两次 `return 257` 可能是同一个对象。这不能写成语言规则。示例断言了动态构造下 256 共享、257 不共享。

### 4. 可变默认参数为什么是坑？

**常见错法：** 默认参数每次调用都会新建一个列表。

**回答：** 默认值在函数定义时求值一次。默认列表被所有省略该参数的调用共享。示例连续调用 `shared_default`，第二次得到 `[1, 2]`。正确写法用 `None` 当哨兵，在函数体内创建新列表。3.15 才有内置 `sentinel`，3.12 用 `object()` 做“不是合法业务值”的哨兵。

### 5. `and` / `or` 返回什么？

**常见错法：** 它们的结果类型一定是 `bool`。

**回答：** `not` 返回布尔。`and` 和 `or` 返回最后被求值的那个操作数，并且会短路。`"" or "fallback"` 的结果是字符串 `"fallback"`。真值还包括非空容器；空容器、`0`、`None`、`False` 为假。示例断言了这条。

### 6. 地板除对负数怎么取整？

**常见错法：** `//` 向零截断，所以 `-7 // 2` 是 `-3`。

**回答：** `//` 向负无穷取整，`-7 // 2` 是 `-4`。余数满足 `a == (a // b) * b + (a % b)`，所以 `-7 % 2` 是 `1`。从向零截断的语言转过来时，这是必考的计算而不是口诀。

### 7. `bool` 和 `int` 是什么关系？

**常见错法：** 布尔和整数完全无关，`True + True` 应当是类型错误。

**回答：** `bool` 是 `int` 的子类。`True == 1`，`True + True == 2`。这是历史设计，不是建议你拿布尔做算术。接口若只想要真假，就按真假使用，不要依赖它等于 1。

### 8. `+=` 对列表和元组一样吗？

**常见错法：** `+=` 总是做成新对象再重新绑定。

**回答：** 列表实现了就地的 `__iadd__`，`items += [2]` 改的是原列表，别名看得到。元组没有就地加法，只能绑定到新元组，旧名字不受影响。示例检查了列表这条。

### 9. 字典和集合的顺序？

**常见错法：** 集合也保证插入顺序，因为某次打印是按顺序的。

**回答：** `dict` 从 3.7 起按插入顺序迭代，这是语言保证。更新已有键不改变位置。`set` 不保证顺序。要去重并保持首次出现顺序，用 `dict.fromkeys`。

### 10. `finally` 里的 `return` 会怎样？

**常见错法：** `finally` 只做清理，不会改变 `try` 里的返回值。

**回答：** `finally` 里的 `return` 会替换 `try` 里准备好的返回值，也会压住正在传播的异常。示例里的函数返回 `2` 而不是 `1`。3.14 起这种离开 `finally` 的 `return`、`break`、`continue` 会得到 `SyntaxWarning`（PEP 765）。3.12 仍然允许，所以不要写。

### 11. 为什么不要写裸 `except:`？

**常见错法：** 裸 `except` 和 `except Exception` 一样。

**回答：** 裸 `except` 连 `BaseException` 都接，包括 `KeyboardInterrupt`、`SystemExit` 和 `GeneratorExit`。普通失败用具体类型。实在要兜底，用 `except Exception`，并且记录之后重新抛出或转换成边界上的错误。取消和中断应当继续传播。

### 12. `*args`、`**kwargs`、`/`、`*` 怎么排？

**常见错法：** `*args` 可以写在仅限关键字参数的后面。

**回答：** 顺序是：位置仅限参数、`/`、普通参数、`*args` 或单独的 `*`、仅限关键字参数、`**kwargs`。`/` 左边不能用关键字传递，`*` 右边必须用关键字。这是调用约定，不是装饰器语法。

### 13. 推导式和普通 `for` 的作用域一样吗？

**常见错法：** 推导式的循环变量会留在外层。

**回答：** 推导式、生成器表达式有自己的作用域，循环变量不泄漏。普通 `for` 的循环变量在语句结束后仍然存在。闭包若直接捕获 `for` 的变量，所有函数看到的是最后一次赋值。用默认参数在定义时绑住当前值。

### 14. f-string 和 t-string 是一回事吗？

**常见错法：** 3.12 已经有 `t"..."`，它会自动转义 HTML。

**回答：** f-string 立刻得到 `str`。`f"{name=}"` 从 3.8 起可以带表达式文本。t-string 是 3.14 的 PEP 750，结果是 `string.templatelib.Template`，保留静态部分和插值，方便调用方自己处理。字母 `t` 不会自动做安全转义。3.12 的示例只用 f-string。

### 15. `match` 里单独的名字是什么？

**常见错法：** `case x` 会和外面的变量 `x` 比较。

**回答：** 单独的名字是捕获，而且几乎什么都匹配。要按已有的值匹配，用点号形式，例如枚举 `Color.RED`，或在守卫里比较。`case int()` 才是类型模式，`case int` 只是把值绑到一个叫 `int` 的名字，还会把内置的 `int` 遮住。字符串也会匹配序列模式，需要的话先写 `case str()`。

### 16. 导入一个模块时发生了什么？

**常见错法：** 导入只是建立一个名字，不执行对方的代码。第二次导入会再执行一遍。

**回答：** 第一次导入会执行模块顶层，并把模块对象放进 `sys.modules`。再导入直接用缓存。顶层因此只放定义，不要连接生产数据库。循环导入时，对方模块对象可能已经在缓存里，但名字还没赋值完，所以不要在顶层调用对方尚未定义的函数。

### 17. 注解会在调用时检查类型吗？3.14 呢？

**常见错法：** 写了 `x: int`，传入字符串就会被解释器拒绝。3.14 的延迟注解等于运行时校验。

**回答：** 注解不插入校验。3.12 默认在函数定义时求值注解。3.14 起默认延迟到读取时，并提供 `annotationlib`。延迟求值仍然不是校验。要拒绝错误输入，在系统边界写解析函数。

### 18. 为什么 `{}` 不是空集合？

**常见错法：** 花括号总是集合。

**回答：** `{}` 是空字典，这是字面量的历史。空集合写 `set()`。非空集合 `{1, 2}` 才是集合。字典推导式带冒号，集合推导式不带。

## 展开

上面每题是口试时的第一段。追问通常落到机制。下面把最容易被追问的六题写成可以继续说的版本。

### 动态强类型，追问“那注解算什么？”

1. 动态和强类型描述的是运行时的对象和运算。`"1"+1` 抛 `TypeError`，名字却可以先绑整数再绑字符串。
2. 注解是另一条通道，给人和类型检查器。3.12 定义时求值，3.14 默认延迟。两条通道都不在调用点插入检查。
3. 所以“我们有类型注解”不能回答“非法 JSON 会不会进库存”。那要看边界解析。

### 传参，追问“列表被改了算传引用吗？”

1. 传的是对象引用。参数名和实参可以指向同一对象。
2. 就地修改可变对象，调用方看得见。重新绑定参数名，调用方看不见。
3. 不要用 C++ 的传值、传引用二分来收尾。隔离要显式拷贝，并说明深浅。

### 地板除，追问恒等式

1. `//` 向负无穷。`-7//2==-4`。
2. `a == (a//b)*b + (a%b)`，所以 `-7%2==1`。
3. 从向零截断的语言迁来的分页和取余会差 1。用 `divmod` 一次拿两个结果，避免手写不一致。

### 可变默认参数，追问“那缓存放哪？”

1. 默认值在 `def` 时求值一次，存在函数对象上。
2. 需要每次新列表就默认 `None`，体内再创建。
3. 有意共享的缓存用 `lru_cache` 或显式对象，并规定上限和失效。不要借默认参数的共享来装缓存。

### `finally` 里的 `return`

1. 它会替换 `try` 里的返回值，也会吞掉正在传播的异常。
2. 3.14 起这种离开 `finally` 的 `return`、`break`、`continue` 会 `SyntaxWarning`。3.12 仍能悄悄跑。
3. 清理放 `with` 或 `finally` 里不带 `return` 的代码。示例里的 noqa 是反例。

### 导入

1. 查 `sys.modules`，没有则创建模块、先放进缓存、再执行顶层。
2. 第二次导入不执行。循环导入会看到执行到一半的模块。
3. 顶层不做连接、不读生产配置。入口放 `main()`，用 `__name__` 判断。

### 加练

1. 用三句话区分 `is`、`==` 和小整数缓存。
2. `{}`、`set()`、`{1}` 分别是什么类型？

参考答案：

1. `is` 是身份，业务相等用 `==`。CPython 缓存 `-5` 到 `256`，另外代码对象会合并相同常量。两者都不是语言保证，不能写进判断。
2. 空字典、空集合、含一个整数的集合。空集合没有字面量，因为 `{}` 已经是字典。
