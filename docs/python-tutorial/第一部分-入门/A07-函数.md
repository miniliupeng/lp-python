# A07　函数

> 示例：`examples/part_a/a07_functions.py`

## 学完你能做什么

定义带默认值和关键字的函数，知道返回值是什么，以及文档字符串放在哪里。参数的全部形式、闭包和作用域在 B01。

## 定义和调用

```python
def area(width: float, height: float = 1.0) -> float:
    """返回宽和高围成的矩形面积。"""
    return width * height
```

调用方式：

- `area(3, 2)`：按位置传入。
- `area(3)`：`height` 使用默认值。
- `area(height=4, width=2)`：按名字传入，顺序可以换。

默认值在 **函数定义时** 求值一次，不是每次调用求值。默认值如果是列表、字典这种可变对象，所有调用会共享它。这是故意的语言规则，也是最常见的坑。入门阶段默认值只用不可变对象：数字、字符串、`None`。可变对象的正确写法在 B01，用 `None` 当哨兵，再在函数体内创建新列表。

## 返回值

没有 `return`，或者 `return` 后面不写值，函数结果是 `None`。`return` 会立刻结束这一次调用。

函数只有一个返回值槽。你写 `return a, b` 时，返回的是 **一个元组**，调用方再解包。这不是某些语言里的多返回值通道。

示例里的 `scale` 返回新列表，不修改传入的列表。入门阶段尽量让函数这样工作：输入进来，新结果出去。需要修改传入对象时，函数名应当明显，例如 `append` 这种。

## 文档字符串

函数体第一条语句如果是字符串字面量，它会成为 `__doc__`。用一句完整的话说这个函数做什么、单位是什么、什么情况下抛异常。不要把实现步骤复述一遍。

帮助系统 `help(area)` 读的就是它。本教程的示例函数保持很短，有些不再重复文档；你自己的库代码应该写。

## 注解仍然不校验

`width: float` 不会让 `area(3, 2)` 在运行时拒绝整数。整数能参与乘法。真正拒绝错误类型，要么你自己 `isinstance`，要么在系统边界用专门的校验库。D03 讨论这件事该放在哪一层。现在不要以为写了注解就安全了。

## 函数也是值

A01 已经把函数赋给别的名字。由此可以得到两个日常用法：把函数放进字典，按名字分派；把函数传给另一个函数，例如 `sorted(rows, key=...)`。`key` 接受一个函数，排序时用它的返回值做比较。A13 的成绩单就这样排。

## 机制

`def` 执行时创建函数对象，并把名字绑到它上面。函数对象带着代码对象、默认值、注解、闭包和限定名。默认值表达式在 `def` 执行时求值一次，不是每次调用求值。可变默认值因此会被所有调用共享。正确写法是默认 `None`，在函数体内再创建新列表。B01 有直接断言。

参数的顺序是：位置或关键字参数，然后 `*args`，然后仅关键字参数，然后 `**kwargs`。3.8 起可以用 `/` 把左边标成仅位置。仅位置适合短小的数学函数，避免关键字把实现细节焊死；仅关键字适合布尔开关，避免调用写成 `f(True, False)` 没人看得懂。

`return` 可以返回任何对象，包括另一个函数。没有 `return` 的函数返回 `None`。返回多个值其实是返回一个元组，调用方再解包。

文档字符串是函数体里的第一条字符串语句，存在 `__doc__`。它不是注释。注释在编译后就没了。类型注解不是文档的替代品：注解说形状，文档说边界条件、单位和失败时抛什么。

函数是一等对象。可以放进列表、当参数、当返回值。装饰器就是利用这一点的函数，B04 再展开。现在只要能写出 `bound = add` 并调用 `bound`。

递归有深度上限，`sys.getrecursionlimit()` 默认大约 1000。能用循环写的不要改成深递归。递归适合树，并且要保证每一步问题变小。

## 会出事的写法

- `def f(items=[])`。第二次调用看见第一次 append 的元素。
- 用可变对象当缓存还放在默认参数里。缓存应该是函数属性或实例属性，并且有上限。
- 函数既改传入的列表又返回一个新列表。调用方无法知道哪一个是结果。选一种：就地改并返回 `None`，或者不改参数、返回新对象。
- 捕获所有异常后 `return None`。调用方分不清“算出了空”和“失败了”。失败用异常，空结果用空容器或明确的返回类型。

## 加练

1. 写 `clip(value, low, high)`，三者都是数，返回落在区间内的值。不要改传入的对象，因为数本来就不可变。
2. 为什么 `def log(msg, buf=[])` 在测试里会串数据？改一版。

参考答案：

1. `return min(high, max(low, value))`。先约定 `low <= high`，否则先抛 `ValueError`。
2. 默认列表只创建一次。改成 `buf=None`，体内 `if buf is None: buf = []`。如果调用方传入列表，就使用那一个，这是显式共享。

## 面试

### Q1. 默认参数什么时候求值？

**考点**：可变默认参数。这是最高频的一题。

**回答**：

1. 在 `def` 执行时求值一次，存在函数对象上。
2. 可变对象会被后续调用共享。表现是“函数记住了上次的列表”。
3. 默认值用 `None`，调用时再创建新容器。需要保留调用方传入的容器时，文档写明会就地修改。

### Q2. `/` 和 `*` 在签名里是什么？

**考点**：调用约定，不是乘法。

**回答**：

1. `/` 左边只能按位置传。`*` 右边只能按关键字传。
2. 仅位置让你以后能改参数名。仅关键字让布尔参数自解释。
3. `*args` 收集多余位置参数，`**kwargs` 收集多余关键字。顺序不能乱。B01 的示例对仅位置参数用关键字调用，断言 `TypeError`。

### Q3. 函数返回 `None` 和没有返回，调用方怎么区分？

**考点**：隐式返回值。

**回答**：

1. 区分不了。都是 `None`。
2. 如果 `None` 是合法结果，失败就不要也返回 `None`。用异常，或者返回一个结果对象。
3. 类型注解写成 `int | None` 是给检查器看的，运行时不会帮你保证这条分支真的只在缺失时出现。

## 常见错误

- 默认参数写成 `def f(items=[])`。先记住“不要这样写”，B01 给可运行的对照。
- 忘记 `return`，函数永远给出 `None`，后面的调用方再去下标，错误会看起来像数据问题。
- 在函数里修改传入的列表，调用方没有预料到。要么文档写明，要么返回新列表。

## 练习

1. 写 `clamp(x, low, high)`，把 `x` 限制在闭区间内。不要改入参。
2. 写 `full_name(first, last="")`，缺省姓氏时只返回名字。说明默认值为什么用 `""` 是安全的。
3. `def pair(a, b): return a, b` 的返回值类型是什么？

参考答案：

1. `return max(low, min(high, x))`。调用前后传入的对象若是数字，本来就不能改。
2. `return first if last == "" else f"{first} {last}"`，形式可以不同。字符串不可变，默认值只求值一次也不会在调用之间串数据。
3. 一个元组，`(a, b)`。

## 小结

位置参数、关键字参数和默认值足够写 A 阶段的程序。默认值只求值一次，所以先不要把可变对象放进去。函数返回一个对象，逗号会把它变成元组。函数本身可以传递。
