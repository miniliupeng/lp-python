# A07　函数

> 示例：`examples/part_a/a07_functions.py`

## 学完你能做什么

定义带默认值和关键字的函数，知道返回值是什么，以及文档字符串放在哪里。参数的全部形式、闭包和作用域在 B01。

## 定义和调用

```python
def area(width: float, height: float = 1.0) -> float:
    """返回宽和高围成的矩形面积。"""
    return width * height
```

调用方式：

- `area(3, 2)`：按位置传入。
- `area(3)`：`height` 使用默认值。
- `area(height=4, width=2)`：按名字传入，顺序可以换。

默认值在 **函数定义时** 求值一次，不是每次调用求值。默认值如果是列表、字典这种可变对象，所有调用会共享它。这是故意的语言规则，也是最常见的坑。入门阶段默认值只用不可变对象：数字、字符串、`None`。可变对象的正确写法在 B01，用 `None` 当哨兵，再在函数体内创建新列表。

## 返回值

没有 `return`，或者 `return` 后面不写值，函数结果是 `None`。`return` 会立刻结束这一次调用。

函数只有一个返回值槽。你写 `return a, b` 时，返回的是 **一个元组**，调用方再解包。这不是某些语言里的多返回值通道。

示例里的 `scale` 返回新列表，不修改传入的列表。入门阶段尽量让函数这样工作：输入进来，新结果出去。需要修改传入对象时，函数名应当明显，例如 `append` 这种。

## 文档字符串

函数体第一条语句如果是字符串字面量，它会成为 `__doc__`。用一句完整的话说这个函数做什么、单位是什么、什么情况下抛异常。不要把实现步骤复述一遍。

帮助系统 `help(area)` 读的就是它。本教程的示例函数保持很短，有些不再重复文档；你自己的库代码应该写。

## 注解仍然不校验

`width: float` 不会让 `area(3, 2)` 在运行时拒绝整数。整数能参与乘法。真正拒绝错误类型，要么你自己 `isinstance`，要么在系统边界用专门的校验库。D03 讨论这件事该放在哪一层。现在不要以为写了注解就安全了。

## 函数也是值

A01 已经把函数赋给别的名字。由此可以得到两个日常用法：把函数放进字典，按名字分派；把函数传给另一个函数，例如 `sorted(rows, key=...)`。`key` 接受一个函数，排序时用它的返回值做比较。A13 的成绩单就这样排。

## 常见错误

- 默认参数写成 `def f(items=[])`。先记住“不要这样写”，B01 给可运行的对照。
- 忘记 `return`，函数永远给出 `None`，后面的调用方再去下标，错误会看起来像数据问题。
- 在函数里修改传入的列表，调用方没有预料到。要么文档写明，要么返回新列表。

## 练习

1. 写 `clamp(x, low, high)`，把 `x` 限制在闭区间内。不要改入参。
2. 写 `full_name(first, last="")`，缺省姓氏时只返回名字。说明默认值为什么用 `""` 是安全的。
3. `def pair(a, b): return a, b` 的返回值类型是什么？

参考答案：

1. `return max(low, min(high, x))`。调用前后传入的对象若是数字，本来就不能改。
2. `return first if last == "" else f"{first} {last}"`，形式可以不同。字符串不可变，默认值只求值一次也不会在调用之间串数据。
3. 一个元组，`(a, b)`。

## 小结

位置参数、关键字参数和默认值足够写 A 阶段的程序。默认值只求值一次，所以先不要把可变对象放进去。函数返回一个对象，逗号会把它变成元组。函数本身可以传递。
