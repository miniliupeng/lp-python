# A05　运算符与表达式

> 示例：`examples/part_a/a05_operators.py`

## 学完你能做什么

读懂短路、链式比较、增强赋值和解包，而不是只记得“加号能加”。

## 比较可以连写

`1 < 2 < 3` 等价于 `1 < 2 and 2 < 3`，中间的 `2` 只计算一次。它不是 `(1 < 2) < 3`。`(1 < 2) < 3` 会先得到 `True`，再和 `3` 比较，而 `True == 1`，所以那个写法碰巧也为真，含义完全不同。写范围时用链式比较，或者写两个明确的比较。

## `and` / `or` / `not`

`not` 的结果一定是布尔。`and` 和 `or` **返回最后被看的那个操作数**，不一定是 `True` 或 `False`。

```python
assert ("" or "fallback") == "fallback"
assert (0 and 1) == 0
assert (1 and "ok") == "ok"
```

假值包括 `False`、`None`、数值 `0`、空容器和空字符串。除此之外的多数对象为真，包括非空字符串 `"0"` 和非零的 `Decimal`。不要用 `if len(items) > 0` 表达“有没有元素”，`if items` 就是空与否；如果你要区分 `None` 和空列表，再写 `is None`。

短路是规定：`and` 在左边为假时不算右边，`or` 在左边为真时不算右边。这可以用来避免无意义的调用，但别写成很难读的链条。复杂条件用中间变量。

## 增强赋值不一定是重新绑定

对列表，`items += [2]` 会调用就地的 `__iadd__`，对象还是原来那个，所有别名都看得到。对元组没有就地加法，`pair += (2,)` 只能算出新元组再绑回名字，旧元组不变。

这是 A02 练习的答案。看到 `+=` 时先问：这个对象可变吗？

## 海象运算符

`:=` 在表达式里完成赋值，3.8 引入。它适合“算出一个值，既要判断又要使用”的场景，例如读入内容后判断是否为空。不要把它塞进很长的一行来炫耀。示例只确认语法：`(n := 4) * n == 16`。

## 字典合并

3.9 起，`{1: "a"} | {1: "b", 2: "c"}` 得到新字典，右边的键覆盖左边。`|=` 则更新左边。这比先 `copy` 再 `update` 好读。

## 解包

```python
first, *rest = [10, 20, 30]
```

`first` 是 `10`，`rest` 是新列表 `[20, 30]`。星号只能出现一次。函数参数里的 `*` 和 `**` 留到 B01，那是定义参数，不是这里的序列解包。

3.15（PEP 798）允许在推导式里写 `*` 和 `**` 解包。3.12 的推导式没有这个语法，示例不使用它。

## 优先级

一元运算、乘除、加减、比较、`not`、`and`、`or`，大致按这个顺序收紧。记不住就加括号。生产代码里，靠读者背优先级才能看懂的表达式应该拆开。

身份比较 `is` 的优先级低于比较运算里的一些组合，这不是你需要探险的地方。比较对象身份时写成单独的布尔表达式。

## 常见错误

- 把 `a < b < c` 理解成两个独立比较的某种平均。它就是 `and`，并且中间值只算一次。
- 认为 `or` 的结果类型一定是 `bool`。只有你再套一层 `bool()` 时才是。
- 对列表使用 `+=` 还以为别的名字看不见。

## 练习

1. `0 or [] or "x"` 的结果是什么？类型是什么？
2. `s = "ab"`，`t = s`，执行 `s += "c"` 后 `t` 是什么？`s is t` 呢？
3. 把 `first, *mid, last = [1, 2, 3, 4]` 的三个名字写出来。

参考答案：

1. 结果是 `"x"`，类型是 `str`。空字符串和空列表都为假，`or` 继续向右看。
2. `t` 仍是 `"ab"`。字符串不可变，`+=` 重新绑定 `s`，`s is t` 为假。
3. `first == 1`，`mid == [2, 3]`，`last == 4`。

## 小结

链式比较是一次 `and`。`and`/`or` 返回操作数并会短路。`+=` 对可变对象可能就地修改。解包和字典 `|` 是日常语法，推导式里的解包要等到 3.15。
