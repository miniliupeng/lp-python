## 赋值是绑定，不是抄一份

Python 里的名字（你习惯叫变量）保存的是 **对对象的引用**。赋值把名字绑到对象上，不负责把对象复制一遍。

```python
shared = [1]
alias = shared
alias.append(2)
assert shared == [1, 2]
assert shared is alias
```

`shared` 和 `alias` 是两个名字，对象只有一个列表。`append` 修改的是这个列表，所以两个名字都看得见。

如果右边是一个新对象，发生的是 **重新绑定**，原来的对象不动：

```python
left = 1
right = left
left = 2
assert right == 1
```

`left = 2` 让名字 `left` 改指整数 `2`。`right` 仍然指着原来的 `1`。整数本身也没有被“改成 2”，因为你根本没有修改那个整数对象。

这不是“传值还是传引用”能干净概括的模型。函数调用时，参数名同样被绑到传入的对象上，和赋值是同一套规则。可变对象在函数里被修改，调用方能看见；对参数名重新赋值，调用方看不见。第二部分会把函数讲完，这里先把模型放对。

## 类型在对象上

`type(1)` 是 `int`，`type("one")` 是 `str`。类型属于对象，不属于名字。所以同一个名字可以先绑整数，再绑字符串：

```python
value = 1
value = "one"
```

这叫 **动态类型**：检查发生在运行时，名字没有固定的静态类型格子。它不等于可以随便把类型混在一个运算里。Python 是 **强类型**：`"1" + 1` 会抛 `TypeError`，解释器不会悄悄把字符串变成整数。需要转换时你自己写 `int("1") + 1`。

`isinstance(True, int)` 为真，是因为 `bool` 是 `int` 的子类，不是因为类型系统含糊。下一章会说明这件事带来的实际后果。

## `is` 和 `==` 从现在就分开

`==` 问“值相不相等”，通常会调用对象的 `__eq__`。`is` 问“是不是同一个对象”。教学示例里用 `is` 暴露别名；业务判断相等时用 `==`。数字和字符串的 `is` 尤其不能当规则用，[C02](../第三部分-运行时/C02-可变性拷贝与身份.md) 会把 CPython 的缓存讲准确。

## 可变和不可变

能否就地修改，是对象的性质：

| 对象 | 能否就地改内容 |
| --- | --- |
| `list`、`dict`、`set`、`bytearray` | 能 |
| `int`、`float`、`str`、`tuple`、`bytes`、`frozenset` | 不能 |

不可变不是“里面的东西永远不变”的递归保证。元组自己的槽位不能换，但槽位里如果放着列表，那个列表仍能改。A08 有例子。

## 机制

一个赋值语句做的事可以压成一句：在某个命名空间里，把左边的名字记到右边那个对象上。它不分配一个“装值的格子”，也不默认复制对象。

名字住在命名空间里，对象住在堆上。你能看见的命名空间主要是这三层：

| 命名空间 | 典型内容 | 怎么看到 |
| --- | --- | --- |
| 局部 | 函数里的赋值目标 | 帧上的局部变量 |
| 全局 | 模块顶层的赋值 | `globals()` 或模块属性 |
| 内建 | `len`、`int`、`open` | 解释器提供，一般不改 |

对象头部至少带着类型指针和引用计数（CPython）。类型决定这个对象能接受什么运算。`len` 成功，是因为对象的类型提供了长度；`len(1)` 失败，是 `int` 没有这个能力，不是名字 `1` 写错了。

调用函数时，参数名在新帧里绑到传入的对象。这和 `alias = shared` 是同一条规则，所以“传对象引用”比“传值还是传引用”准确。两条推论要同时记住：

- 函数里对可变对象做就地修改，调用方看得到，因为两边名字指向同一个对象。
- 函数里给参数名重新赋值，只改新帧里的绑定，调用方的名字不动。

`==` 走 `__eq__`，问值。`is` 比较身份，问是不是同一个对象。`None` 用 `is`，因为缺失就是那个唯一对象。数字和字符串用 `==`。CPython 会缓存一部分小整数和短字符串，那是实现，不是语言规则，C02 把边界画清楚。

## 会出事的写法

- `b = a` 之后就地改 `b`，以为 `a` 还是旧内容。列表、字典、集合、自定义可变对象都会中招。
- 为了“隔离”写 `b = a` 或 `b = a[:]` 却没想清楚要不要拷贝嵌套。浅拷贝只复制最外一层。嵌套列表仍共享。见 C02。
- 把动态类型说成弱类型，于是写出 `"1" + 1` 这种从 JavaScript 带过来的习惯。Python 这里抛 `TypeError`。
- 用 `is` 比较从配置、JSON、数据库读出来的数字。就算今天碰巧为真，也只说明缓存或常量表碰对了。

## 示例对照

`examples/part_a/a02_names_and_objects.py` 按这个顺序证明：

1. `alias.append(2)` 之后 `shared == [1, 2]` 且 `shared is alias`。两个名字，一个列表。
2. `left = 2` 之后 `right == 1`。整数没有被改写，变的是 `left` 这个名字。
3. 同一个名字先绑 `1` 再绑 `"one"`。类型跟着对象走。
4. `"1" + 1` 必须是 `TypeError`。示例用 `try` 把“没抛异常”也当成失败。
5. `type(1) is int`，以及 `isinstance(True, int)`。后一条是因为 `bool` 继承 `int`，不是因为 `True` 的类型含糊。

## 加练

1. 函数 `def push(box, item): box.append(item)`，调用 `push(data, 1)` 之后 `data` 变了。把函数改成 `box = box + [item]`，`data` 还变吗？
2. `a = 1000`，`b = 1000`，在一个函数里写两个字面量，`a is b` 可能为真。这能不能当成业务规则？

参考答案：

1. 不变。`+` 造出新列表，函数里的 `box` 改绑到新列表，调用方的名字仍指旧列表。就地 `append` 才会共享修改。
2. 不能。那是同一个代码对象的常量合并，或者小整数缓存。业务相等只用 `==`。动态构造 `int("1000") is int("1000")` 在 CPython 上为假。

## 面试

### Q1. Python 是强类型还是弱类型？动态和静态又是哪一条？

**考点**：两组概念是正交的，不要用“有没有写类型”来回答。

**回答**：

1. 动态：名字没有固定类型格子，类型挂在对象上，检查发生在运算当时。
2. 强类型：不兼容的运算不会悄悄转换。`"1" + 1` 是 `TypeError`，不会变成 `"11"` 或 `2`。
3. 注解和 mypy、Pyright 是另一层静态检查。它们不改变上面两条。3.10 以上的 `int | None` 仍然只是注解。

### Q2. 参数是传值还是传引用？

**考点**：别名和重新绑定。

**回答**：

1. 传的是对象引用。参数名和实参名可以指向同一个对象。
2. 就地修改可变对象，调用方可见。给参数名重新赋值，调用方不可见。
3. 需要隔离时显式拷贝，并说明浅拷贝还是深拷贝。不要指望赋值帮你拷贝。

### Q3. 什么时候用 `is`，什么时候用 `==`？

**考点**：身份、相等，以及 CPython 缓存能不能进业务代码。

**回答**：

1. `is` 只用于身份：`None`、哨兵对象、以及你故意要证明两个名字共享对象的教学断言。
2. 数值、字符串、业务对象用 `==`。相等可以跨类型，`False == 0` 为真，但 `False is 0` 为假。
3. CPython 缓存 `-5` 到 `256`，编译期还会合并代码对象里的相同常量。`257 is 257` 在源码里甚至会得到 `SyntaxWarning`。这些都不能写成判断条件。

## 常见错误

- 把 `b = a` 理解成深拷贝。那是第二个名字。
- 为了“防止被改”只是再赋一个名字。要拷贝必须显式做，见 C02。
- 看到动态类型就写成“Python 没有类型”。对象一直有类型，只是名字不固定。

## 练习

1. `a = [1, 2]`，`b = a`，`b = b + [3]` 之后 `a` 是什么？`a is b` 呢？
2. 把上一题的 `b = b + [3]` 换成 `b += [3]`，答案变了吗？为什么先别急着背，做完去看 A05。
3. 为什么 `len(1)` 报错，而 `len("1")` 不报错？

参考答案：

1. `a` 仍是 `[1, 2]`。`+` 生成新列表并让 `b` 重新绑定，所以 `a is b` 为假。
2. 对列表来说 `+=` 会就地扩展，`a` 变成 `[1, 2, 3]`，而且 `a is b`。细节在 A05，和“不可变对象的 `+=` 只能重新绑定”对照着记。
3. `len` 要求对象提供长度。整数没有，字符串有。这是对象能力的差别，不是名字的差别。

## 小结

名字绑定对象。赋值不复制。类型在对象上，运算不帮你做隐式的字符串和数字转换。两个名字可以指向同一个可变对象，这是后面绝大多数“我没改过它啊”的来源。
