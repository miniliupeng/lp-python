# B02　推导式与迭代协议

> 示例：`examples/part_b/b02_iterables.py`

## 学完你能做什么

说清 `for` 实际调用了什么，区分可迭代对象和迭代器，并用推导式写出过滤后的新容器。

## `for` 在做什么

`for item in obj` 大致是：

1. 调用 `iter(obj)`，得到迭代器。
2. 反复 `next(iterator)`。
3. 迭代器抛 `StopIteration` 时结束。这个异常由 `for` 接住，不会冒到你的业务代码。

可迭代对象实现 `__iter__`，每次 `iter()` 可以给出一个新迭代器。列表就是这样：`list(data)` 做两遍，两遍都完整。

迭代器实现 `__next__`，通常 `__iter__` 返回自己。它有状态，耗尽之后再 `next` 只会继续抛 `StopIteration`。示例把列表的迭代器取走一个元素，剩下的 `list(iterator)` 只有后半段，而且再调用 `next` 会失败。

所以：列表可以反复遍历；从它得到的迭代器不行。生成器表达式、文件对象、`map` 的返回值多数是一次性的。把一个迭代器传给两个消费者，第二个会看到空的。

## 自己写可迭代对象

`CountDown` 的 `__iter__` 是生成器函数。每次 `iter()` 都从 `start` 重新开始。这是“可重复遍历”的关键：`__iter__` 不要返回一个已经走了一半的共享迭代器，除非你有意这样做。

不要自己用 `raise StopIteration` 从生成器里结束迭代。生成器里的 `return` 会转换成 `StopIteration`。在生成器里直接 `raise StopIteration` 会被解释器当成别的错误（3.7 起是 `RuntimeError`）。用 `return`。

## 推导式

```python
[n * n for n in range(4) if n % 2 == 0]
```

这是新列表。`if` 是过滤，不是三元表达式。集合推导式用 `{}`，字典推导式是 `{键: 值 for ...}`。空集合不是 `{}`，`{}` 是空字典；空集合写 `set()`。

生成器表达式把方括号换成圆括号，结果是迭代器，不立刻把元素都算出来。它适合交给 `sum`、`any`、`max` 这种只遍历一次的函数。如果后面要遍历两遍，先做成列表，或者接受重新创建生成器。

推导式有自己的作用域。推导式里的循环变量不会漏到外面。这和 Python 2 不同，也和普通 `for` 不同：普通 `for` 的循环变量在循环结束后仍然存在。

3.15（PEP 798）允许在推导式里写 `*` 和 `**` 解包。3.12 没有这个语法。要拼平一层嵌套，3.12 用循环或 `itertools.chain.from_iterable`。

## 常见错误

- 对一个迭代器调用两次 `list`，第二次是空的，还以为数据丢了。
- 用推导式做有副作用的事情，比如在里面 `append` 到外部列表。推导式是表达式，副作用放进普通循环更清楚。
- 写 `{x for x in items}` 只为了去重，然后依赖遍历顺序。集合不保证顺序。要保持首次出现的顺序，用 A08 的 `dict.fromkeys`。

## 练习

1. 写一个函数，判断可迭代对象里有没有负数。不要把它整个变成列表。
2. 解释 `squares = (n * n for n in range(3))` 之后，为什么 `next` 一次再 `list` 一次，结果里没有 `0`。
3. 字典推导式怎么从 `[("a", 1), ("b", 2)]` 得到 `{"a": 1, "b": 2}`？

参考答案：

1. `return any(n < 0 for n in values)`。`any` 碰到第一个真值就停止。
2. 生成器表达式是一次性迭代器。`0` 已经被 `next` 取走了。
3. `{key: value for key, value in pairs}`。

## 小结

`for` 是 `iter` 加 `next`。可迭代对象可以重新开始，迭代器通常不能。推导式制造新容器，生成器表达式制造一次性管道。过滤条件写在 `for` 后面。
