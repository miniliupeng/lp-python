# B11　常用标准库进阶

> 示例：`examples/part_b/b11_stdlib_advanced.py`

## 学完你能做什么

在写自己的小容器之前，先用 `collections`、`itertools`、`functools` 和 `re` 里已经定好语义的工具。

## `Counter`、`deque`、`defaultdict`

`Counter` 是计数字典。不存在的键当 0 处理，`most_common(1)` 给出出现最多的一项。它仍然是字典，键的要求和字典一样。

`deque` 是双端队列。两端的添加和弹出都是 O(1)。列表在开头插入是 O(n)。需要队列或滑动窗口时用 `deque`，不要用列表的 `pop(0)` 硬撑。`deque` 按下标访问中间元素是 O(n)，它不是更好的列表。

`defaultdict(list)` 在键缺失时调用工厂。示例里 `grouped["k"].append("v")` 不必先判断键在不在。工厂对每个缺失键调用一次。不要用一个共享的可变对象当工厂的返回值，工厂应该是 `list`、`int` 这种每次给出新值的可调用对象。`defaultdict` 的“缺失就创建”有时会把拼写错误的键也变成条目。对外的查询接口如果拼错键应该报错，就不要用它，用普通字典的 `setdefault` 或显式判断。

## `batched` 和 `groupby`

`itertools.batched(values, 2)` 从 3.12 开始有。它把序列按固定长度切开，最后一组可以不足。示例里 5 个数变成 `(1, 2)`、`(3, 4)`、`(5,)`。自己写切片循环容易在最后一组上出错，优先用它。

`groupby` 只把 **相邻** 的相同键合成一组。输入没有按键排好时，相同的键会被拆成多段。示例的 `rows` 已经按键放在一起。真实数据先 `sorted`，再 `groupby`。它返回的组迭代器必须在请求下一个键之前消费完，因为内部只走一次底层迭代器。示例在进入下一组之前就把当前组收成了列表。

## `functools.cache`

`@cache` 记住参数到返回值的映射。`fib(8)` 这样带大量重复子问题的递归，从指数变成线性。缓存是进程内的字典，参数必须可哈希。它不会过期，也不会限制大小。结果集很大时用 `@lru_cache(maxsize=...)`，否则这个字典会一直长。

带副作用的函数不要缓存。缓存键是参数，默认参数、可变的全局数据都不在键里。方法上使用时，`self` 也是键的一部分，每个实例各有一份缓存。

`partial` 用来固定一个函数的部分参数，得到新的可调用对象。它比 `lambda` 更容易看出还缺哪些参数。

## 正则

`re.findall(r"\d+", "a12b3")` 得到数字串列表。模式用原始字符串，减少一层反斜杠。需要反复使用的模式用 `re.compile`，编译结果可以在循环外做一次。

正则不是解析 HTML、JSON 或任意嵌套结构的工具。那些格式有自己的解析器。正则适合形态固定的一小段文本：标识符、数字、分隔符。复杂的正则要配几个输入例子放在测试里，否则下一次修改没人敢动。

`findall` 在模式有分组时，返回分组而不是整个匹配。这经常让人以为“正则坏了”。想要整个匹配，就不要加捕获分组，或使用 `(?:...)` 非捕获组。

## 日期只再提醒一次

计算时间差用 `datetime` 和 `timedelta`。带时区的瞬间用 `datetime.now(UTC)`。把字符串解析成时间时，格式要显式写出，失败会抛 `ValueError`，让边界代码去处理。不要用切片假设日期永远是 `YYYY-MM-DD` 而不检查。

## 常见错误

- `groupby` 之前不排序，统计结果随输入顺序变化。
- `@cache` 放在接收字典的函数上，调用时才发现字典不可哈希。
- 用 `re.match` 找中间的子串。`match` 只从开头尝试。中间用 `search`。

## 练习

1. 用 `Counter` 找出 `"banana"` 里出现最多的字母。并列时 `most_common` 的顺序以它的实现为准，测试写最多次数是 3 即可，字母是 `a`。
2. 用 `batched` 把 0 到 4 分成二元组，最后一组应当只有一个元素。
3. 什么输入会让 `groupby` 把同一个键分成两组？

参考答案：

1. `Counter("banana").most_common(1)[0] == ("a", 3)`。
2. `list(batched(range(5), 2))` 的最后一项是 `(4,)`。
3. 相同的键不相邻，例如 `[("a", 1), ("b", 2), ("a", 3)]`。`a` 会出现两次。

## 小结

双端用 `deque`，计数用 `Counter`，相邻分组用 `groupby` 且先排序，定长切片用 3.12 的 `batched`。缓存只加在纯函数上，并且要有尺寸上限的意识。正则处理扁平文本，不替代解析器。
