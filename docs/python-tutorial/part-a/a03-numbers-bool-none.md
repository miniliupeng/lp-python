# A03　数字、布尔与 None

> 示例：`examples/part_a/a03_numbers.py`

## 学完你能做什么

选对数字类型，写对负数除法，并且不把 `True`、`None`、`nan` 用错。

## 整数没有固定宽度

`int` 可以大到只受内存限制，不是 C 的 64 位整数。日常加减不用担心溢出。代价是超大整数的运算不再是固定时间，面试里如果有人问“Python 整数加法是不是 O(1)”，答案是：小整数近似是，位数上去以后不是。

## 除法有两种

`/` 是真除法，结果是 `float`：`7 / 2 == 3.5`。`//` 是 **向负无穷取整** 的地板除，不是“向零截断”。

```text
-7 // 2 == -4
-7 % 2 == 1
```

恒等式是 `a == (a // b) * b + (a % b)`。余数的符号跟着除数走。从 C、Java 转过来的人很容易在这里算错。

## 二进制浮点不是十进制

`0.1 + 0.2 != 0.3` 在 IEEE 754 双精度下成立，不是 Python 的 bug。`float` 适合测量、图形、科学计算里本来就是近似的量。钱、税率、需要十进制精确分数的量用 `decimal.Decimal`，并且用字符串构造：

```python
from decimal import Decimal

assert Decimal("0.1") + Decimal("0.2") == Decimal("0.3")
```

`Decimal(0.1)` 会把已经不精确的二进制浮点再包一层，通常不是你想要的。

## `bool` 是 `int` 的子类

`True` 和 `False` 是仅有的两个布尔对象。`True == 1`，`True + True == 2`，`isinstance(True, int)` 为真。这是历史设计，不是建议你拿布尔做算术。需要计数时用整数；需要真假时用布尔。

`False == 0` 和 `False == 0.0` 都为真，因为数值相等不要求类型相同。身份则不同：`False is 0` 为假。

## `None` 是单例

“没有值”用 `None`，不要用 `0`、`""` 或 `False` 代替，除非这些值在你的领域里真的表示缺失。判断缺失写 `x is None` 或 `x is not None`。`None` 在进程里只有一个对象，所以这里用 `is` 是语言习惯，也和实现一致。

示例里有一行 `None == None`，只是为了说明相等性同样成立。风格检查会提醒你改成 `is`。听这个提醒。

## `nan` 不等于自己

`float("nan") != float("nan")`。它还会让一些比较和字典键变得反直觉。不要用 `nan` 当哨兵，缺失用 `None`。检查 NaN 用 `math.isnan`。

## 小整数缓存不是 `257 is 257` 能证明的

**语言不保证** 两个相等的整数是同一个对象。CPython 有两件容易混在一起的实现细节：

1. 启动时准备了 `-5` 到 `256` 这些整数对象。动态造出来的 `int("256")` 和另一个 `int("256")` 是同一个对象；`int("257")` 不是。
2. 编译一个函数时，相同的常量会放进这个代码对象的常量表。`return 257` 每执行一次都取出 **同一格** 常量，所以 `returns_257() is returns_257()` 为真。这不能证明 `257` 进了全局缓存。

业务代码用 `==` 比较数字。只在讲解对象身份时，才用 `int("256")` 这种动态构造观察缓存。

## 常见错误

- 用 `float` 记账，最后差一分钱。
- 认为 `//` 对负数是向零取整。
- 把 `True` 放进数值接口还觉得“只是布尔”。调用方如果写了 `if flag == 1` 以外的算术，结果会让你吃惊。
- 用 `x is 256` 做判断。3.12 会对这种写法发出 `SyntaxWarning`。

## 练习

1. 计算 `-11 // 3` 和 `-11 % 3`，用恒等式验算。
2. 用 `Decimal` 计算 `1 / 10 + 2 / 10` 的精确十进制结果。注意怎么构造。
3. 说明 `returns_257() is returns_257()` 为真，并不能推出“所有 257 都是同一个对象”。

参考答案：

1. `-11 // 3 == -4`，`-11 % 3 == 1`，因为 `-4 * 3 + 1 == -11`。
2. `Decimal("0.1") + Decimal("0.2")`，或者 `Decimal(1) / Decimal(10) + Decimal(2) / Decimal(10)`。不要从 `float` 转。
3. 两次调用返回的是同一个代码对象里的同一项常量。`int("257") is int("257")` 为假，说明全局并没有把 257 收成单例。

## 小结

整数可以很大，地板除向负无穷取整，钱用 `Decimal`。`bool` 是整数的子类，`None` 用 `is` 判断，`nan` 不等于自己。整数身份是 CPython 细节，比较数值请用 `==`。
