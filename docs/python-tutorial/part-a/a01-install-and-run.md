# A01　安装、运行，以及 Python 到底在执行什么

> 示例：`examples/part_a/a01_run_model.py`。本章示例在 CPython 3.12 上运行。

## 学完你能做什么

装好解释器，用三种方式运行代码，并说清“Python 不是逐行读源码然后立刻做运算”这件事。

## 安装与确认

本教程的可执行示例锁定 **CPython 3.12**。2026 年 11 月的最新稳定版是 3.15，但示例故意不使用 3.13 及以上的语法，这样在 3.12 上就能原样跑通。更高版本的增量放在 [C07](../part-c/c07-runtime-2026.md)。

```bash
python3 --version
python3 examples/part_a/a01_run_model.py
```

看到 `Python 3.12.x` 和 `ok a01` 即可。如果系统里的 `python` 和 `python3` 不是同一个程序，后文统一写 `python`，你在本机把它换成实际可用的命令。

不要用操作系统自带的、且低于 3.12 的 Python 来跑本教程。类型联合 `int | None`、`list[int]` 这些写法我们会直接用，它们从 3.9 / 3.10 起可用，但教程整体按 3.12 讲述。

## 三种运行方式

1. **交互式解释器**。终端输入 `python` 回车，出现 `>>>`。适合验证一个表达式。退出用 `exit()` 或 Ctrl-D。
2. **脚本**。把代码放进 `hello.py`，执行 `python hello.py`。解释器会把该文件当成 `__main__` 模块执行。
3. **以模块方式运行**。`python -m 包名` 会按导入规则找这个包并执行它。后面讲包的时候会用到。和“随便给一个文件路径”相比，`-m` 的当前包上下文是明确的。

交互式适合提问，脚本适合保存。教程里的结论都以脚本里的 `assert` 为准：断言失败，进程以非零状态退出，`examples/run_all.py` 会把它算作错误。

## 源码会先变成字节码

CPython 执行一个函数时，大致是：

1. 解析源码，生成抽象语法树。
2. 编译成 **字节码**，放进代码对象（`code` object）。函数的 `__code__` 就是它。
3. 解释器在一个 **帧**（frame）里执行这些字节码。函数调用会压入新的帧。

所以“Python 是解释型语言”这句话太粗。更准确的说法是：CPython 先把源码编译成字节码，再由虚拟机执行。3.11 起这个虚拟机带有自适应的特化指令；3.13 起还有实验性的 JIT，而且默认不开。这些是后话，A 阶段只需要留下这个模型：

```text
源码 → 字节码（代码对象）→ 虚拟机在帧里执行
```

你现在不需要读字节码。需要拆开看的时候去 [C04](../part-c/c04-bytecode.md)。

## 语句和表达式

表达式算出一个值，例如 `1 + 2`、`add(2, 3)`。语句完成一件事，例如 `assert`、赋值、`def`、`if`。

函数由 `def` 定义。定义本身是一条语句，执行到它时，Python 创建一个函数对象，并把名字绑到这个对象上。因此函数可以赋给另一个名字，也可以当参数传递。`a01` 里的 `bound = add` 就是在做这件事。

```python
def add(left: int, right: int) -> int:
    return left + right

bound = add
assert bound(10, 1) == 11
```

冒号后面的 `int` 是 **注解**，给人和类型检查器看。CPython 3.12 不会因为你传入字符串就在调用时抛出类型错误。注解什么时候求值，[B09](../part-b/b09-type-hints.md) 再讲。现在不要把注解理解成自动校验。

## `if __name__ == "__main__"`

一个文件被 `python file.py` 直接运行时，模块名是 `"__main__"`。它被别的文件 `import` 时，模块名是文件名。把演示和断言放进 `main()`，再用下面的判断调用，这个文件就既能当脚本跑，也能被导入而不自动跑演示。

```python
if __name__ == "__main__":
    main()
```

## 缩进是语法

Python 用缩进表示块，同一块里的缩进必须一致。本教程和示例使用 4 个空格，不使用 Tab。冒号 `:` 引出一个新块：`def`、`if`、`for`、`while`、`with`、`class` 都是这样。

## 常见错误

- 把交互式里的 `>>>` 抄进脚本。那是提示符，不是代码。
- 认为“装了 Python 就等于装了本仓库的 FastAPI 等依赖”。本教程 `examples/` 只使用标准库。
- 用 `python` 跑 2.7 或 3.8 的解释器，然后觉得教程代码“不能运行”。先看 `--version`。

## 练习

1. 写一个函数 `triple(n)`，返回 `n * 3`。用断言检查 `triple(4) == 12`。
2. 把这个函数赋给名字 `f`，通过 `f` 调用它。
3. 解释：为什么把文件导入进另一个程序时，顶层的 `print` 会执行，而放在 `main()` 里且由 `__name__` 判断保护的 `print` 不会。

参考答案：

1. `def triple(n): return n * 3`，再 `assert triple(4) == 12`。
2. `f = triple`，`assert f(4) == 12`。两个名字指向同一个函数对象。
3. 导入会执行模块顶层语句，用来完成定义。`__name__` 只有在直接运行时才是 `"__main__"`，所以那一层保护下的调用不会在导入时发生。

## 小结

安装的是 CPython 3.12。脚本、交互式和 `python -m` 是三条入口。函数是对象。解释器执行的是编译后的字节码，不是源码文本本身。
