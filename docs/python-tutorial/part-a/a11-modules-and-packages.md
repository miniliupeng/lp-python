# A11　模块、包与导入

> 示例：`examples/part_a/a11_modules.py`，以及同目录的 `demo_pkg` 和 `cycle_demo`。

## 学完你能做什么

把函数放进模块和包，知道 `import` 会执行什么，以及循环导入在什么时候会炸。

## 模块就是一个执行过的文件

`import demo_pkg` 时，解释器找到包，执行它的 `__init__.py`，把产生的模块对象放进 `sys.modules`。以后再导入同一个模块，直接用缓存，顶层代码不会再跑一遍。

顶层代码因此应该只做定义和必要的初始化。导入时去连数据库、读用户输入，都会让“只是想用一个函数”变得很贵，也很难测试。

`demo_pkg/__init__.py` 从子模块取出 `clip` 再放进 `__all__`。调用方可以写：

```python
from demo_pkg import clip
```

`__all__` 影响的是 `from demo_pkg import *` 和阅读时的公开面。它 **不会** 阻止别人写 `from demo_pkg.mathutil import clip`。约定是：没有下划线前缀的名字都可能被用到。不要靠 `__all__` 隐藏秘密。

示例把 `examples/part_a` 插进 `sys.path`，这样无论你从仓库根目录还是从别的目录启动，都能找到这两个教学包。应用程序里更干净的做法是把包安装进环境，而不是在运行时改 `sys.path`。D01 会讲安装。

## 包是带 `__init__.py` 的目录

本教程的包都保留 `__init__.py`，这叫普通包。没有这个文件的目录在某些条件下能成为命名空间包，那是给大型插件分布用的，入门阶段不要靠它碰运气。

包里的导入使用包的全名，例如 `from demo_pkg.mathutil import clip`。不要在包内用修改 `sys.path` 的方式去“找到隔壁文件”。

## `__name__` 再出现一次

直接运行文件时名字是 `"__main__"`。被导入时名字是模块的点分路径。A01 的守卫在这里仍然适用：演示放在守卫下面，导入包不会把 `print("ok")` 打出来。

`python -m demo_pkg` 这种运行方式和直接跑某个文件不同，包的 `__package__` 会被设置好，相对导入才有着落。教学示例不使用相对导入，减少一条失败路径。你在真实包里写 `from .mathutil import clip` 是合理的，但那个文件必须作为包的一部分被导入，不能被当成孤立脚本运行。

## 循环导入

`left.py` 导入 `right.py`，`right.py` 又导入 `left.py`。这能工作，是因为两边都只在 **函数内部** 使用对方的名字。导入 `right` 时，`left` 可能还没执行完，模块对象已经在 `sys.modules` 里，但 `label` 可能尚未赋值。函数要等到调用时才去取 `left.label`，那时两个模块都执行完了。

如果在 `right.py` 的顶层立刻调用 `left.label()`，导入期会抛 `AttributeError`。循环导入不是“Python 不允许两个文件互相引用”，而是“顶层执行到一半时，名字可能还不存在”。

能拆开就拆开：把两边共同依赖的函数挪到第三个模块。必须互引时，把使用放进函数或方法，不要放在顶层。

## 常见错误

- 在库模块顶层打开配置文件并退出进程。导入不应该决定程序的生死，让 `main()` 去做。
- 循环导入后用try/except把 `ImportError` 吞掉，得到一个半初始化的模块。
- 测试时忘记 `sys.modules` 里已经有旧模块。需要真的重新执行模块时，测试框架会处理隔离；随便 `import` 两次不会重跑顶层代码。

## 练习

1. 在 `demo_pkg` 里找到 `clip(10, 0, 3)` 的结果是怎么来的，写出调用链。
2. 为什么 `via_left()` 可以在导入完成后调用，却不应该搬到 `right.py` 的顶层？
3. 同一个进程里两次 `import demo_pkg`，`mathutil.py` 的顶层会执行几次？

参考答案：

1. `a11_modules.py` 导入 `demo_pkg` 包，包的 `__init__.py` 从 `mathutil` 导入 `clip`。`clip` 用 `max`/`min` 把 10 夹到 3。
2. 顶层执行发生在对方模块还可能没定义完的时候。函数体推迟到调用时才解析 `left.label`。
3. 一次。第二次命中 `sys.modules`。

## 小结

导入会执行模块顶层并缓存模块对象。包用目录和 `__init__.py` 组织公开函数。循环导入时不要在顶层使用尚未定义完的名字。程序的副作用留在 `main()`。
