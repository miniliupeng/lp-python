# C10　深挖对照实验

> 示例：`examples/part_c/c10_lab.py`

## 学完你能做什么

把 C 部最容易说错的六句话，各自对应到一条会失败的断言上。这一章不引入新机制，用来复查。

## 六条结论

1. **小整数缓存不等于字面量规则。** `int("256") is int("256")` 为真，`int("257") is int("257")` 为假。动态构造才能看见缓存边界。字面量 `257` 仍可能因代码对象常量合并而共享。
2. **浅拷贝共享内层。** `copy.copy` 出一个新外层列表后，修改内层，原对象能看见。需要隔离就 `deepcopy`，并接受它复制不了的资源类型。
3. **GIL 的切换间隔不是锁。** `sys.getswitchinterval()` 大于 0，只说明解释器会在线程之间让出字节码执行权。它不使 `+=` 变原子。
4. **取消不是普通异常。** `asyncio.CancelledError` 不是 `Exception` 的子类。写 `except Exception` 不会处理取消，也不应该靠扩大捕获去处理它。
5. **`bool` 是 `int` 的子类。** `issubclass(bool, int)` 为真。需要真假值时用布尔语义，不要在接口里做算术还声称自己只接收布尔。
6. **字典顺序是插入顺序。** 先插入 `b` 再插入 `a`，`list(order)` 是 `["b", "a"]`。这是 3.7 以来的语言保证。集合没有这条保证，实验里故意不用集合。

示例把这六条放在一个进程里跑完。任何一条断言失败，都是这一章和解释器不一致，而不是“面试答案有多种说法”。

## 怎么用这个实验准备面试

先盖住本章，自己写出上面六句话的理由，再跑示例。理由要能区分：

- 语言参考里的保证（字典顺序、`CancelledError` 的基类、`bool` 的继承）。
- CPython 的实现（小整数缓存、切换间隔的具体默认值）。

切换间隔的 **默认值** 是 0.005 秒，C05 断言了精确默认值。本章只要求它是正数，因为这一条要复习的是“它存在且不是锁”，不是把一个调参常量再说一遍。别人的进程可能调用过 `sys.setswitchinterval`。

## 不要从实验里多推出来的话

- 不要推出“所有小于 257 的整数在任何实现里都是单例”。那是 CPython 的缓存。
- 不要推出“浅拷贝一定更快所以应该总用浅拷贝”。快不快要测，对不对要看内层是否可变。
- 不要推出“3.15 已经没有 GIL”。C07 的地图仍然有效：默认构建有 GIL，自由线程是可选项。

## 机制

这一章把前面的结论收成可以复述的实验，而不是新的语言规则。六条值得钉死：

1. 赋值是绑定。别名就地改，两边都看见。
2. 浅拷贝和深拷贝差在第几层。
3. 无环对象在 CPython 里引用计数到 0 就回收；环要 `gc.collect`。
4. `+=` 对列表是就地的，对整数是重新绑定。
5. 带锁的计数是确定的；无锁交错不是一个稳定断言。
6. 注解不阻止 `double("ab")`。

实验的读法：每条断言对应一条可以在面试里说出来的句子。不要从实验多推。例如进程池这次比线程快，不能推出“以后都用进程”。示例故意不做这种计时比较。

准备面试时盖住结论，先自己写预测，再跑 `examples/part_c/c10_lab.py`。预测错了就回到对应章节，不要在实验文件里改断言去迁就预测。

## 会出事的写法

- 把实验机器的耗时写进笔记当语言规则。
- 用 `is` 比较字面量 `257` 来“证明缓存”。常量合并会骗你。用 `int("257")`。
- 实验里 `except Exception: pass`。失败被吃掉，对照就没有意义。
- 只跑成功的那条断言。反例才是实验的主体。

## 面试

### Q1. 你会用哪三个实验证明你理解对象模型？

**考点**：能不能选对证据。

**回答**：

1. 两个名字指向一个列表，`append` 两边可见，`is` 为真。
2. 浅拷贝后改内层两边都变，深拷贝后只变一边。
3. 动态 `int("257")` 不是同一个对象，但函数常量 `257` 可能是。这说明缓存和常量合并是两件事。

### Q2. 实验失败时应该改断言还是改理解？

**考点**：规格的地位。

**回答**：

1. 断言写的是解释器已经表现出的语言和实现事实。
2. 预测错了就改理解，回到对应章。
3. 只有发现断言本身和文档矛盾，才改断言，并说明版本。

### Q3. 为什么对照实验不测速度？

**考点**：正确性和性能分开。

**回答**：

1. 速度依赖机器、负载和解释器版本。
2. 这一章要固定的是语义。语义不稳定，速度没有意义。
3. 性能放到 C09，用 profiler，并且不断言某一个毫秒数。

## 练习

1. 给这个文件加一条断言：空集合的字面量不能写成 `{}`。用 `type({}) is dict` 即可。
2. 为什么这条实验不检查 `frozendict`？
3. 选一条你曾经记错的结论，写成“错法 / 为什么错 / 哪条断言能抓住它”。

参考答案：

1. `assert type({}) is dict` 和 `assert type(set()) is set`。`{}` 是空字典。
2. 3.12 没有这个内置类型。版本探测在 C07，不把 3.15 语法写进公共示例。
3. 例如错法是“`except Exception` 能接住任务取消”。它错在继承关系。`not issubclass(asyncio.CancelledError, Exception)` 能抓住。
